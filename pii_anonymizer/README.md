# המקודד של ליאור - הסתרת מידע מזהה (PII) בקבצי אקסל

כלי שמסתיר מידע מזהה (ת.ז, שמות, ח.פ/עוסק מורשה, טלפון, מייל, כתובת, וכל מידע
אחר שתסמנו) בקובץ אקסל לפני העלאה לכלי AI כמו קלוד, ומאפשר לשחזר את הקובץ
המעובד בחזרה עם הנתונים המקוריים - מבלי שמידע מזהה יצא מהמחשב שלך.
זמין הן כשורת פקודה (`anonymize.py` / `restore.py`) והן כממשק ווב מקומי (`streamlit_app.py`).

קובץ המיפוי (`mapping.json`) הוא הקובץ היחיד שמקשר בין הקודים לערכים האמיתיים.
**אסור להעלות אותו לשום מקום** - הוא נשאר אצלך מקומית בלבד.

## התקנה

```bash
pip install -r requirements.txt
```

## שלב 1: הסתרת מידע לפני העלאה

```bash
python anonymize.py --in data.xlsx --out anon.xlsx --mapping mapping.json
```

הכלי מצפין רק עמודות שמסומנות ידנית, בשתי דרכים אפשריות:
- הוסיפו את המילה **"תקודד"** (עם או בלי מרכאות) לכותרת העמודה - למשל
  "שם פרטי תקודד".
- צבעו את תא הכותרת במילוי רקע **שחור** עם גופן **לבן**.

כל הערכים בעמודה המסומנת (כל השורות מתחת לכותרת) יוצפנו אוטומטית.
עמודות שלא מסומנות כך לא ייגעו בהן.

כעת ניתן להעלות את `anon.xlsx` בבטחה לקלוד ולהריץ עליו את כל מה שצריך.
**שמרו את `mapping.json` במחשב שלכם - אל תעלו אותו לשום מקום.**

## שלב 2: שחזור הקובץ המעובד שחוזר מקלוד

```bash
python restore.py --in result.xlsx --out final.xlsx --mapping mapping.json
```

הכלי סורק כל תא בכל הגיליונות בקובץ (כולל גיליונות חדשים שנוספו בעיבוד, וקודים
שמופיעים בתוך טקסט חופשי) ומחזיר את הערכים המקוריים במקום הקודים, לפי קובץ
המיפוי שנוצר בשלב 1.

## ממשק ווב (Streamlit)

מי שמעדיף ממשק גרפי במקום שורת פקודה יכול להריץ:

```bash
streamlit run streamlit_app.py
```

הממשק ייפתח בדפדפן בכתובת `http://localhost:8501` ומריץ הכל מקומית בלבד - שום קובץ
לא נשלח לאינטרנט. כולל שני טאבים: הסתרת מידע ושחזור הקובץ שחוזר מעובד.

בממשק הווב **אין צורך לערוך את הקובץ מראש**: אחרי העלאת הקובץ מוצגת רשימת
העמודות של כל גיליון, ובוחרים מתוכה אילו עמודות להצפין. עמודות שכבר סומנו
בקובץ (המילה "תקודד" בכותרת או צביעה שחורה עם גופן לבן) מופיעות מסומנות
מראש, ואפשר להוסיף או להסיר בחירה לפני ההצפנה. הסימון בכותרת נשאר רלוונטי
בעיקר לשימוש בשורת הפקודה (`anonymize.py`).

לכל עמודה שנבחרה אפשר לקבוע את **סוג המידע** (שם, ת.ז, ח.פ/עוסק מורשה,
שם חברה, טלפון, מייל, כתובת או כללי). הסוג מנוחש אוטומטית לפי כותרת העמודה
וניתן לשינוי, והוא קובע את תחילית הקוד בקובץ המקודד - למשל `[[NAME_0001]]`
לשם ו-`[[PHONE_0001]]` לטלפון - כך שהקובץ המקודד נשאר קריא וברור גם לכלי
ה-AI שמעבד אותו.
