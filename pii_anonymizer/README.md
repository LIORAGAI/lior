# הסתרת מידע מזהה (PII) בקבצי אקסל

כלי שמסתיר מידע מזהה (ת.ז, שמות, ח.פ/עוסק מורשה, טלפון, מייל, כתובת)
בקובץ אקסל לפני העלאה לכלי AI כמו קלוד, ומאפשר לשחזר את הקובץ המעובד בחזרה
עם הנתונים המקוריים - מבלי שמידע מזהה יצא מהמחשב שלך.
זמין הן כשורת פקודה (`anonymize.py` / `restore.py`) והן כממשק ווב מקומי (`streamlit_app.py`).

קובץ המיפוי (`mapping.json`) הוא הקובץ היחיד שמקשר בין הקודים לערכים האמיתיים.
**אסור להעלות אותו לשום מקום** - הוא נשאר אצלך מקומית בלבד.

## התקנה

```bash
pip install -r requirements.txt
```

## שלב 1: הסתרת מידע לפני העלאה

```bash
python anonymize.py --in data.xlsx --out anon.xlsx --mapping mapping.json
```

הכלי מזהה אוטומטית עמודות לפי כותרת (כגון "ת.ז", "שם פרטי", "ח.פ", "טלפון", "מייל")
ולפי תוכן (מספרי ת.ז עם ספרת ביקורת תקנית, כתובות מייל, מספרי טלפון). ההרצה אינה
כוללת שאלות אינטראקטיביות - אם משהו לא זוהה אוטומטית, יש לסמן אותו ידנית בצביעה
שחורה (ראו למטה) ולהריץ שוב.

ניתן גם לסמן ידנית עמודה/תאים להסתרה: צבעו רקע שחור (מילוי שחור) על כל התאים
בעמודה (כולל הכותרת) - הכלי יזהה את הסימון ויקודד את כל השורות בעמודה אוטומטית,
גם בלי לעבור דרך הזיהוי האוטומטי. אפשר גם לצבוע תאים בודדים (לא עמודה שלמה)
ואלו יוסתרו בנפרד.

כעת ניתן להעלות את `anon.xlsx` בבטחה לקלוד ולהריץ עליו את כל מה שצריך.
**שמרו את `mapping.json` במחשב שלכם - אל תעלו אותו לשום מקום.**

## שלב 2: שחזור הקובץ המעובד שחוזר מקלוד

```bash
python restore.py --in result.xlsx --out final.xlsx --mapping mapping.json
```

הכלי סורק כל תא בקובץ (כולל קודים שמופיעים בתוך טקסט חופשי) ומחזיר את הערכים
המקוריים במקום הקודים, לפי קובץ המיפוי שנוצר בשלב 1.

## ממשק ווב (Streamlit)

מי שמעדיף ממשק גרפי במקום שורת פקודה יכול להריץ:

```bash
streamlit run streamlit_app.py
```

הממשק ייפתח בדפדפן בכתובת `http://localhost:8501` ומריץ הכל מקומית בלבד - שום קובץ
לא נשלח לאינטרנט. כולל שני טאבים: הסתרת מידע (זיהוי אוטומטי, עם כפתורי הורדה
לקובץ המקודד ולקובץ המיפוי) ושחזור הקובץ שחוזר מעובד.
