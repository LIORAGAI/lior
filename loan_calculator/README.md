# מחשבון הלוואה – Tharros

קובץ יחיד: `tharros-loan-calculator.html`. הקובץ עצמאי (HTML, CSS ו-JavaScript בתוך הקובץ, ללא ספריות חיצוניות). העיצוב מוגבל למזהה `#tharros-loan-calc`, ולכן אינו משפיע על שאר האתר.

## הגדרות לפני העלאה
1. **לוגו** – בשורה `data-logo="LOGO_URL_HERE"` יש להחליף בכתובת המלאה של קובץ הלוגו (לאחר העלאתו לספריית המדיה של האתר). אם לא מוחלף, הלוגו פשוט לא יוצג.
2. **צבעי מותג** – בשורת ה-CSS הראשונה: `--tlc-primary` (צבע ראשי) ו-`--tlc-accent` (צבע משני).

## שיטות חישוב
1. שפיצר – החזר חודשי קבוע: PMT = L·r / (1 − (1+r)^−n), כאשר r היא הריבית השנתית חלקי 12.
2. קרן שווה – החזר קרן קבוע של L/n, ריבית על היתרה.
3. בלון – תשלום ריבית חודשי ופירעון הקרן כולה בתשלום האחרון.
4. גרייס – בחודשי הגרייס משולמת ריבית בלבד, והקרן נפרסת על יתרת התקופה.

## העלאה לאתר
1. **וורדפרס (עורך בלוקים)**: הוספת בלוק "HTML מותאם אישית" והדבקת כל תוכן הקובץ.
2. **אלמנטור**: גרירת ווידג'ט "HTML" והדבקת כל תוכן הקובץ.
3. **וויקס**: "הוספה" ← "הטמעת קוד" ← "הטמעת HTML" ← "קוד", והדבקת כל תוכן הקובץ.
4. **כל פלטפורמה אחרת**: העלאת הקובץ לשרת והטמעה באמצעות `<iframe src="…/tharros-loan-calculator.html" width="100%" height="1400" style="border:0"></iframe>`.
